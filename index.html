🔐 Encriptador con clave automática🕵🏼

Instrucciones:

1️⃣ Escribe tu mensaje en el recuadro inferior.

2️⃣ Presiona "✨ Encriptar" para generar mensaje cifrado y clave.

3️⃣ Copia el mensaje y la clave para enviarlo.

4️⃣ Para desencriptar, pega el mensaje cifrado y la clave, luego presiona "💡 Desencriptar".

5️⃣ Usa el botón "📋 Copiar resultado" para copiar fácilmente.
